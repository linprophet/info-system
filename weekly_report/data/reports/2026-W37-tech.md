- [传字节开发实时空间视频生成模型；微信内测「AI 社交」功能；华为小米同天发布折叠屏手机](http://www.geekpark.net/news/369965) — _极客公园_ · 字节正基于现有电影级视频生成模型 **Seedance** 构建实时空间视频生成模型，功能对标 Google Genie，可生成响应 Pico 头显用户语音或动作的虚拟世界，面向直播、短剧、游戏场景。架构上把生成这一计算密集型任务完全放到云端，以降低头显端算力要求、支撑更廉价简化的硬件。同篇另报微信内测"小微 AI 社交"：两个 AI 助手先对话，用户仅在授权与决策环节介入。

**为什么本周值得看**：Agent 的能力瓶颈正从"模型够不够聪明"转向"环境是否可被感知、接口是否可被解析"。一条线是给 Agent 装身体（硬件感知入口），另一条线是让软件产品主动为 Agent 做适配。

- [走出聊天框，Agent 开始进入现实世界](http://www.geekpark.net/news/370064) — _极客公园_ · 文章梳理 Agent 从文件/网页/软件走向物理世界的路径：腾讯 WorkBuddy 生态发布九款联名智能硬件（智能眼镜、录音卡、麦克风、耳机、桌面陪伴设备）承担声音与图像采集，WorkBuddy 负责理解、规划与执行；Google 将 Gemini for Home 带入音箱、摄像机、门铃；Amazon 用 Alexa+ 连接智能家居与多终端；百度"搭子"落地小度添添闺蜜机 Ultra、智能屏 X9 Ultra、摄像机 C1500、音箱 Pro Max 四条产品线。核心论点是 Agent 需要摄像头、麦克风、屏幕、传感器作为感知与触达入口。
- [判断用不用你的软件，Agent 只需 500 个 Token](http://www.geekpark.net/news/369960) — _极客公园_ · 介绍 Google Cloud AI 工程总监 Addy Osmani 提出的 **AEO（Agentic Engine Optimization）**：为 AI Agent 优化 API 与文档，类比 SEO。文中给出具体场景——Agent 请求支付 API 文档，400ms 内做出判断，但文档近 20 万 Token 远超上下文窗口，Agent 不报错而是直接编造不存在的接口。结论是产品对 Agent 的友好度（而非模型智能）决定了集成成功率。
- [童欣加入 Meshy，3D 世界终于等到自己的「互联网时刻」](http://www.geekpark.net/news/369959) — _极客公园_ · 图形学学者童欣（前微软亚研院首席研究员、网络图形组负责人）加入 Meshy。文章以 2016 年 VR 第一波浪潮为对照，回顾硬件、资本、开发者三方共识如何落空，讨论 3D 生成是否正走到类似"互联网 + 文字/图片/视频"的临界点。
