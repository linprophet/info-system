### 🧠 VLM / LLM Post-training

**本周一句话**: 本周最集中的信号是"跳出 next-token"——NCP 在概念层加目标、diffusion-augmented LLM 在采样层并行出 token、Kalman Delta Networks 给线性注意力记忆加不确定性；同时 benchmark 侧一口气补了 wearable 健康推理、细粒度图像差异、空间积木三块空白。

- **[NCP-ArchPreview Technical Report: Moving towards Latent Space Language Models through Next Concept Prediction](https://huggingface.co/papers/2609.10715)** — _HF Papers · score 0.8_
  在 NTP 之外增加 Next Concept Prediction：从模型自身 hidden state 构造乘积量化概念词表，用专门 Concept Module 预测跨多 token 的未来概念，再回灌到 token 层引导生成，NTP/NCP 端到端联合训练，已 scale 到 8.9B。
- **[Unlocking Lossless Speedups in LLMs via Discrete Diffusion](https://huggingface.co/papers/2609.04010)** — _HF Papers · score 0.78_

- **[WearableQA: A Benchmark for Health Reasoning over Real-World Wearable Data](https://huggingface.co/papers/2609.05405)** — _HF Papers · score 0.85_

### 🎯 Agent RL & Reasoning

**本周一句话**: 两条主线——一条是把 RL 的瓶颈从"生成"挪到"环境执行"（AutoResearch 用 world model 替代真实沙箱），另一条是把 verifier 信号用得更细（FlowBalance 校准自引导、T1 用通过 verifier 数做密集奖励）。

- **[T1: Terminal Agent Reinforcement Learning for Long-Horizon Tasks](https://huggingface.co/papers/2609.11042)** — _HF Papers · score 0.88_
  122B MoE 在云沙箱里操作真实 shell，单任务最多 300+ 轮工具调用，奖励来自执行任务自带 verifier；配方包括激进 warm-start 稳定 actor-critic、按通过 verifier 绝对数打分的密集过程奖励、TITO 构造（在精确采样 token id 上训练 + turn 边界漂移修复）与 rollout routing replay（记录采样器每 token 的专家选择）。
- **[An Open Recipe for IMO Gold: Training Nemotron for Olympiad Mathematics](https://huggingface.co/papers/2609.10712)** — _HF Papers · score 0.85_
  从 Nemotron 3 Ultra 出发用 SFT + RL 训两个专家 checkpoint，系统考察 checkpoint 选择、验证与精修；最终流水线完全用自然语言、无形式化证明器/外部工具/联网，三个 checkpoint 驱动"生成-验证-精修"迭代搜索，再由独立高算力阶段选最终提交，得分 42 分中的 30 分。
- **[Scaling Automatic Research Agents via World Models](https://huggingface.co/papers/2608.12564)** — _HF Papers · score 0.82_
  指出 AutoResearch agent 的 RL 扩展存在根本张力：生成可批处理共享算力，而每次环境执行独占沙箱与真实机器时间，轨迹变长后环境执行成为成本瓶颈；论文据此提出基于 world model 的扩展方案。
- **[Miles v0.1: Production-Level Post-Training](https://huggingface.co/papers/2609.08368)** — _HF Papers · score 0.82_
  全栈生产级后训练系统，沿用 slime 的干净设计，每个 RL 环节以"可验证、干净、可定制"为原则：rollout 引擎基于 SGLang，trainer 可选 NVIDIA Megatron-LM 或 PyTorch FSDP 后端，三种权重同步传输适配不同部署拓扑；除全参 RL 外还支持 LoRA RL、on-policy 蒸馏与 SFT。
- **[FlowBalance: Verifier-Grounded Self-Improvement from On-Policy Reasoning Experience](https://huggingface.co/papers/2609.03241)** — _HF Papers · score 0.78_
  学习完整回答上的归一化分布：对每条 on-policy 轨迹，用同一策略的冻结训练时视图在特权上下文下产生 token 级 log-prob 增益并聚合成轨迹级自引导分数，再用 verifier 导出的组优势做校准——正优势轨迹保留引导、负优势轨迹反转引导，避免强化错误自信或收敛到单一解法模式。
- **[Online Draft Co-Training for Speculative Decoding in Large-Scale, Long-Context RL Post-Training](https://huggingface.co/papers/2609.07108)** — _HF Papers · score 0.7_
  针对大规模长上下文 RL 后训练中 draft 在线协同训练的两个障碍——标准因果 CP 不支持 branch attention、target 特征跨 PP stage——分别用扩展的 packed 负载均衡 zigzag ring attention（合并 rank 局部 branch attention 与因果主序列 attention）和 TapChannel 独立通路传输中间特征解决。
- **[BeaconKV: Key-Value Cache Compression Guided by Beacon Queries for Efficient Large Reasoning Model Inference](https://huggingface.co/papers/2609.04971)** — _HF Papers · score 0.55_
  指出"用近期 query 估计未来 token 重要性"在长程推理中失效：某些解码步会产生 Thought Revisiting Tokens，重新关注早期制定的解题计划；作者发现这些 TRT 对应的 query 聚成小簇，据此设计 beacon query 引导的 KV 压缩。

### 🌍 World Models

- **[Programmable World Model](https://huggingface.co/papers/2609.10540)** — _HF Papers · score 0.85_
