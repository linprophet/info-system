### 🛠️ Agent & Coding Tools

**本周一句话**: 本周 agent 方向的核心词是「harness」——从 Raven 的 harness-of-harnesses 到 Mid-Harness 的 action 验证，再到 Meta-Skill 的 harness 自动设计，社区明显从「造更强模型」转向「造更强执行环境」。同时基准建设密集：EngiWorld 把评测推进到专业工程域，TraceDance 则从真实部署 trace 反向生成行为基准。

- **[Raven: The Harness of Harnesses for Composable Agentic Intelligence](https://huggingface.co/papers/2609.33439)** — _HF Papers · score 0.82_
  开源多智能体生态，自动为特定模型与领域构建并进化模块化 harness，把每个可执行的 model–harness 对视为可组合的智能单元，目标是长程跨域工作流的自动编排。
- **[EngiWorld: What Can Frontier Agents Deliver in Professional Engineering Environments?](https://huggingface.co/papers/2609.37686)** — _HF Papers · score 0.86_
  首个围绕完整设计闭环构建的工程基准：1,301 个专家任务、6 大工程域、26 个专业软件平台，GUI 与 CLI 双接口，并配套统一的 domain-verifier 套件做 artifact-centric 评测。
- **[Mid-Harness: Scaling Actions Between Model and Harness for Terminal Agents](https://huggingface.co/papers/2609.39982)** — _HF Papers · score 0.82_
  NVIDIA 在 model–harness 边界分配 test-time compute：采样并验证候选动作后再执行。关键发现是弱验证下增加采样几乎无收益，而强 verifier 能显著提升轨迹成功率。
- **[TraceDance: Building Agent Behavior Benchmarks from Real-World Deployment Traces](https://huggingface.co/papers/2609.33295)** — _HF Papers · score 0.83_
  ByteDance 系统从真实部署 trace 自动构建针对特定不良行为的基准，Anchor-and-Confirm 结合可编程检索与 Flash LLM 候选确认，用 decision-point continuation 免环境重放地评测。
- **[Learning Meta-Skills for Agent Harness Design in Test-Time AI4AI](https://huggingface.co/papers/2609.38143)** — _HF Papers · score 0.74_
  Builder 在权重冻结下学习可复用的 Meta-Skill 原则（何时需要支持、提供什么资源），在 Harness-Bench 与 NewtonBench 上比无 skill 构建提升 8.95 个百分点，比直接交付 skill bank 提升 12.02 点。
- **[Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States](https://huggingface.co/papers/2610.01415)** — _HF Papers · score 0.75_
  PoS 推理时框架持续维护显式 belief state（世界状态估计 + 未解决任务需求），并监测「Belief Trapping」——智能体持续行动却无实质进展——按 trapping 模式定制恢复策略。
- **[Omni-IO Skills: Harnessing Your Agent Omni-Native](https://huggingface.co/papers/2609.31847)** — _HF Papers · score 0.72_
  即插即用 harness，通过分层 Skills、标准化多模态执行接口、依赖感知编排与持久 Asset Registry，让现有 agent 无需模型更新即可处理文本/图像/音频/视频/3D/代码多资产工作流。

### 🎯 Agent RL & Reasoning

**本周一句话**: 本周 on-policy distillation 成为绝对主线——七篇里有五篇围绕 OPD 展开，从 scaling law、representation residual 外推到多教师归一化，几乎把这个方向拆解了一遍。同时两篇「反直觉」论文值得注意：Meta 的 sharpening tax 与 co-cheating 诊断，都在质疑自演化/后训练闭环的可靠性。

- **[Sharpening Tax in Post-Training](https://huggingface.co/papers/2610.01509)** — _HF Papers · score 0.78_
  Meta 的意外发现：RL 后训练的「锐化税」（提升单次准确率但牺牲解覆盖）未必延伸到 agentic 任务。预训练 LLM 配轻量推理 harness 虽 pass@1 远低，但在充足 test-time budget 下 pass@K 常超过后训练版本。
- **[False Frontiers: Diagnosing and Mitigating Co-Cheating in Self-Evolving Search Agents](https://huggingface.co/papers/2609.39102)** — _HF Papers · score 0.74_
  揭示自演化搜索智能体的「co-cheating」失效模式：proposer 与 solver 逐渐在共享错误上达成一致，内部 reward 提升但外部正确性停滞甚至下降；提出 multi-sample verification 在训练前验证提案。
- **[Scaling Properties of Same-Family On-Policy Distillation](https://huggingface.co/papers/2609.32722)** — _HF Papers · score 0.73_
  系统研究 OPD 在 weak-to-strong / same-base / strong-to-weak 三种设置下的 scaling：早期训练统一呈现「useful-transfer」区间，held-out 准确率随 sqrt-KL 近似线性上升；所有 weak-to-strong 对中学生的峰值 gold score 都超过教师。
- **[The Teacher Is a Direction, Not a Destination](https://huggingface.co/papers/2609.36484)** — _HF Papers · score 0.72_
  指出 LM head 会各向异性地衰减教师隐状态变化，且采样 token 的 log-prob 比率会注入噪声导致训练不稳；改为外推 RL 引起的表示残差方向，让学生在输出空间超越教师。
- **[Groupwise Agentic Grading and Advantage Redistribution for Code Agent RL](https://huggingface.co/papers/2609.32577)** — _HF Papers · score 0.72_
  GAGAR 针对 GRPO 在代码 agent 上给所有通过测试的轨迹分配相同 advantage 的问题，用 SFT 训练的 agentic grader 在同一 workspace 内联合检查同组轨迹，实现质量感知的 credit 重分配。
- **[Beyond Teacher Assignment: Domain-Normalized Multi-Teacher On-Policy Distillation](https://huggingface.co/papers/2609.35347)** — _HF Papers · score 0.70_
  在 Qwen3.5 三个尺寸上发现 MOPD 学生打不过最佳单专家，原因是反馈不平衡（instruction-following 反馈方差是数学专家的数倍）；提出按域归一化教师反馈强度。
- **[On-Policy or Off-Policy Learning? A Systematic Study of Distillation Dynamics](https://huggingface.co/papers/2609.35259)** — _HF Papers · score 0.68_
  在强到弱蒸馏中独立变化 rollout policy、token 级 KL 方向与学习率，跨 Llama3/Qwen2.5 与科学/医学/算术任务发现：rollout policy 未必是核心因素，token 级 KL 方向更主导蒸馏动态。

### 🎨 Image Generation

**本周一句话**: 三篇都指向同一个问题——生成模型与「可验证/可控制」之间的鸿沟。TRM 把 reward 从标量变成 case-adaptive rubric，MaLiang-Harness 把生成变成可检查可修订的程序，FuseReg 则从表征层面调和重建与生成的取舍。

- **[Think Before You Score: Thinking Reward Model for Visual Generation](https://huggingface.co/papers/2609.37372)** — _HF Papers · score 0.76_
  TRM 先为每个 case 制定自适应 rubric 再做 rubric-guided 评估，输出细粒度 pointwise reward；同时指出常规 pairwise 偏好优化会导致分数极化，提出 PD-GRPO 缓解。
- **[MaLiang-Harness: A Programmable Path to Image and Video Generation](https://huggingface.co/papers/2609.34309)** — _HF Papers · score 0.68_
  定义 Program-to-Visual gap（程序正确执行但违反构图/外观/运动要求），用 Persistent Executable Generation 状态与 Traceable Generation Process 把生成组织成持续的构建-检查-修订循环。
- **[FuseReg: Regularizing Layer Fusion in Representation Autoencoders](https://huggingface.co/papers/2609.31620)** — _HF Papers · score 0.63_
  RAE 中浅层保细节、深层利生成的取舍被固定启发式层融合所耦合；FuseReg 改为在编码器层随机子集上训练，理论上证明子集采样显式惩罚跨层敏感性，从而解耦两阶段需求。

### 🎬 Video Generation

**本周一句话**: 两篇分别处理长视频记忆与多奖励优化——前者用「实体传记」解决跨小时的身份消歧，后者让 reward routing 随训练动态调整，共同点是都放弃了静态/固定策略。

- **[Beyond the Timeline: Augmenting Long-Video Memory with Grounded Entity Biographies](https://huggingface.co/papers/2609.38155)** — _HF Papers · score 0.78_
  GEB 把跨片段的同一物理实例的视觉 grounded 观测聚合成可检索的「传记」，解决纯文本实体描述无法消歧、同一物体跨事件断连的问题，问答时传记与 episodic evidence 一同检索。
- **[Adaptive Reward Routing: Dynamic Multi-Reward Optimization for Joint Audio-Video Diffusion](https://huggingface.co/papers/2609.37200)** — _HF Papers · score 0.72_
  针对多奖励 RL 中「更新作用在哪」与「奖励如何组合」两个随训练变化的量，提出在 forward-process RL（DiffusionNFT）中联合自适应更新位置与奖励协调，替代固定 routing 与权重。

### 🤖 VLA & Embodied

**本周一句话**: 三篇都在处理「表示」问题——把隐式编码的动作序列变成显式可检查的程序、把技能结构先验作为组合接口、把全景视觉真正用起来。共同判断是：直接 observation→action 的映射泛化性不足。

- **[Self-Evolving Coding Agents: From Digital Programs to Physical-World Intelligence](https://huggingface.co/papers/2609.35432)** — _HF Papers · score 0.80_
  指出 VLA/WAM 把任务需求、条件、进度与失败恢复都隐式编码进动作序列，导致布局/视角微变即失败；主张用显式可执行代码状态替代，让物理经验回流为可复用程序、记忆或证据。
- **[Agent Priors-guided Policy Learning](https://huggingface.co/papers/2609.35690)** — _HF Papers · score 0.70_
  少样本机器人学习需要组合泛化与技能泛化互相依赖，但组合层只能通过名称/指令等描述看到技能，丢失了策略训练时的结构信息；提出用每个策略的结构先验（如抓取只依赖夹爪位姿）作为组合与技能之间的接口。
- **[PanoVLN: Towards Effective Panoramic Vision-and-Language Navigation](https://huggingface.co/papers/2609.34759)** — _HF Papers · score 0.62_
  发现简单把透视图像换成全景只带来有限增益；诊断认为充分利用更宽视野需要同时修改动作预测、训练监督与视觉表示三处。

### 🧠 VLM / LLM Post-training

**本周一句话**: 本周最密集的方向，两条主线清晰：一是循环/连续扩散等非自回归架构的探索（LoopVL、HC-DLM），二是对后训练副作用的深挖（behavioral shadows、latent evidence-credit gap、rhetorical robustness）。同时音频/语音基准集中发布（VoxMem、Duplex-MPE、Open TTS Leaderboard），多模态记忆与全双工交互正成为新的评测前沿。

- **[Gemini 4 Argon: our next era of frontier intelligence](https://deepmind.google/blog/gemini-4-argon-our-next-era-of-frontier-intelligence/)** — _Google DeepMind Blog · score 0.90_
  DeepMind 新前沿模型，面向长程编码、企业知识工作与网络防御；据 dair.ai 报道在 DeepSWE v1.1 上达 77.9% SOTA，先通过 Fairwind Program 向可信网络防御方开放。
- **[VoxMem: Benchmarking Multimodal Memory in Large Audio Language Models](https://huggingface.co/papers/2609.32607)** — _HF Papers · score 0.80_
  语音记忆不止「说了什么」，还包括谁说的、怎么说的、有什么声音——这些只存在于音频信号中。VoxMem 覆盖多会话、多操作类型的多模态记忆评测，填补现有基准在词汇内容、记忆操作、单会话三方面的不足。
- **[Duplex-MPE: Benchmarking Multi-Party Interaction in Full-Duplex Dialogue](https://huggingface.co/papers/2609.31948)** — _HF Papers · score 0.80_
  2,000 个场景、3-4 位人类说话者加一个助手，每个请求都有显式与隐式指代两个版本；模型接收无转写、无轮次边界的连续音频，用四项分数衡量何时应答、何时沉默、何时停止说话。
- **[Open TTS Leaderboard: Scalable Evaluation for Multilingual TTS and Voice Cloning](https://huggingface.co/blog/open-tts-leaderboard)** — _HF Papers · score 0.80_
  可扩展的多语言 TTS 与声音克隆评测套件，提供跨模型对比。
- **[LoopVL: Recurrent Visual Intelligence](https://huggingface.co/papers/2609.38426)** — _HF Papers · score 0.78_
  结合 Module-Loop 与 Model-Loop 计算，通过共享模块迭代更新统一视觉-语言状态；从零训练（语言预训练→多模态→后训练）后在多模态理解与视觉推理上超越同尺寸及更大非循环模型，并观察到跨循环视觉注意力显著迁移的「Visual Aha Moments」。
- **[UniEvo-VL: An On-policy Self-Distillation Training Recipe for Multimodal Self-improvement](https://huggingface.co/papers/2609.38721)** — _HF Papers · score 0.76_
  单一多模态模型同时扮演教师与学生：学生只看原始问题，教师额外条件于自我批评（privileged information），训练最小化两者在去噪扩散分布上的 per-state 散度，无需外部更大教师。
- **[Rethinking Latent Visual Reasoning: Grounding Latent Reasoning in Visual Evidence](https://huggingface.co/papers/2609.34563)** — _HF Papers · score 0.74_
  识别出「latent evidence-credit gap」：latent token 对改变正确答案的图像扰动响应微弱，根源是 GRPO 训练缺乏显式监督；最终答案 reward 无法指导该保留哪些视觉证据、如何在 latent token 间分配 credit。

### 🌍 World Models

**本周一句话**: 三篇共同指向「actor-centric 世界模型的盲区」——离开视野的物体状态如何维持、latent 未来建模是否真的带来泛化、以及如何系统审计 3D 世界中的异常。显式未来建模的价值被重新确认。

- **[WorldAuditBench: Interactive 3D World Auditing with Multimodal Agents](https://huggingface.co/papers/2609.40325)** — _HF Papers · score 0.85_
  3D 世界审计需要「导航搜索」与「视觉推理」两种能力的紧耦合，基准系统评测 VLM/VLA 能否发现悬浮物体、可穿越墙壁等异常，此前这一能力基本未被探索。
- **[World Observer: Joint Actor-Observer Generation for Persistent World Modeling](https://huggingface.co/papers/2610.02162)** — _HF Papers · score 0.79_
  把「观察」与「行动」解耦：联合生成一个 actor 视角与一个或多个全景 observer，让离开 actor 视野的物体在 observer 中持续演化，重新进入视野时状态得到反映；actor 与 observer 通过共享全景源 warp 做 grounding。
- **[What Makes World Action Models Generalize? An Empirical Study of Test-Time Future Modeling](https://huggingface.co/papers/2609.34981)** — _HF Papers · score 0.76_
  受控对比（匹配 backbone、数据、预算）显示：latent WAM 虽在分布内任务上与 explicit WAM 持平，但在环境扰动、数据效率、任务泛化三个轴上一致退化——动作专家不再条件于未来时，WAM 最初的泛化动机就失效了。

## 📊 本周观察 / Editor's Note

本周两个跨方向信号值得留意。其一，**on-policy distillation 正在被系统性拆解**：七篇 agent-RL 里五篇围绕 OPD，从 scaling law、表示残差外推、多教师归一化到 token 级监督路由，几乎把这个方向的方法空间扫了一遍——同时 Meta 的 sharpening tax 与 co-cheating 诊断从反面质疑后训练闭环的可靠性，两条线可能在下一轮汇合。其二，**「harness」成为 agent 方向的新抽象层**：Raven、Mid-Harness、Meta-Skill、Omni-IO Skills 不约而同地把执行环境当作可学习、可组合、可进化的对象，而非手工工程——这与 VLA 方向「把隐式动作序列变成显式可检查程序」的诉求（Self-Evolving Coding Agents）在哲学上高度一致。
