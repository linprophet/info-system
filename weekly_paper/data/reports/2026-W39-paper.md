### 🛠️ Agent & Coding Tools

**本周一句话**: 本周 agent 侧的主线是"harness 本身成为被优化的对象"——递归自改进、harness 蒸馏、记忆读写时机、多智能体去中心化编排同时出现，且都开始认真对待 OOD 泛化与成本。另一个明显信号是评测从"端到端成功率"转向过程质量（taste、多时间尺度、可验证环境）。

- **[The Tasteful Agent: Measuring and Improving Taste in Long-Horizon Tasks](https://huggingface.co/papers/2609.25804)** — _HF Papers · score 0.85_
  Microsoft 提出 Taste-Bench，从 agent 在工程/研究任务中产生的真实轨迹自动构造"决策分叉"问题，首次把长程决策质量（taste）作为可测量能力，并给出改进方法。填补了现有 benchmark 只测端到端成功、不测过程决策的空白。
- **[GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay](https://huggingface.co/papers/2609.25001)** — _HF Papers · score 0.85_
  Tencent 的 GameHorizon-Annotator 自动标注多时间尺度指令，并据此构建首个大规模 AAA 游戏数据集，统一评测视觉理解、指令分解、目标规划与精确动作控制，避免高方差在线 rollout。
- **[RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents](https://huggingface.co/papers/2609.22000)** — _HF Papers · score 0.85_
  Qwen 的五平台框架：给定一个正在运行的参考实现，agent 必须自行发现其行为并构建忠实复刻，无预设工作流；运行中的参考充当隐藏行为 oracle，使 GUI 探索、编码与视觉验证可被统一验证。
- **[RRSI: Regularized Recursive Self-Improvement of Agent Harnesses](https://huggingface.co/papers/2609.24972)** — _HF Papers · score 0.82_
  Google 指出 harness 的递归演化会通过记忆训练任务过拟合，in-distribution 增益在 OOD 上缩水甚至消失；RRSI 在候选提议与选择两端引入正则化约束来保住泛化。
- **[MintAct: A Unified Visual Agent for Digital Environments](https://huggingface.co/papers/2609.22083)** — _HF Papers · score 0.82_
  Apple 的 2B/4B/8B VLM 家族，统一 UI grounding、移动/桌面/Web 多步导航与视觉工具使用，匹配各领域专家模型；配套异步 RL 框架在数百并发异构后端上稳定训练并显式控制跨域分布。
- **[Harness-Zero: Harness Distillation via Agent-as-Harness](https://huggingface.co/papers/2609.24974)** — _HF Papers · score 0.80_
  北大提出 harness 蒸馏：把领域/实例优化过的 harness 作为训练期指导，将其诱导的行为迁移进模型权重，使增益在部署时单一固定 harness 下依然存活——难点在于两个 harness 的动作空间与可用信息不同，不能直接当监督。
- **[Agensh: Scaling Organizational Intelligence to 1,024 Agents](https://huggingface.co/papers/2609.26781)** — _HF Papers · score 0.72_
  Microsoft Research 的无中心编排多智能体 harness：并发 worker 通过"认领-自分配子任务-行动-共享发现-验证-合并"的异步协作循环扩展至 1,024 个 agent，绕开中心 orchestrator 的调度容量瓶颈。

### 🎯 Agent RL & Reasoning

**本周一句话**: 两条互补路线——一条把 RL 环境从代码本身规模化生成，一条从 Policy Mirror Descent 出发给出 critic-free 的轨迹级目标。共同点是都在降低 RLVR 对人工构造任务与价值网络的依赖。

- **[CodeMidas: Scaling Agentic Coding RL Environments from Code Itself](https://huggingface.co/papers/2609.22068)** — _HF Papers · score 0.83_
  Xiaomi MiMo 的 agentic pipeline 仅以源码为任务特定输入，让 agent 探索已实现功能以形成行为规格、基于原代码执行构造测试、并通过执行验证筛选候选任务，把 RL 环境来源从 issue/commit 扩展到任意已实现功能。
- **[Bellman Policy Optimization](https://huggingface.co/papers/2609.15987)** — _HF Papers · score 0.82_
  BPO 从 Policy Mirror Descent 推导，用 Bellman 方程把 PMD 重构成轨迹级目标，避免估计中间状态价值，并证明与原 PMD 目标有同一唯一最优解；实际损失中的 mismatch-correction 权重是互补 token 概率的平滑比值，在数学推理基准上验证有效。

### 🎨 Image Generation

**本周一句话**: 本周图像侧的共同主题是"给开放式生成找可靠信号"——颜色用 24-bit hex 做统一接口，SVG 用 rubric 替代会引发 reward hacking 的 CLIP/Aesthetic 标量，VQ tokenizer 则回到训练稳定性这一被忽视的基础问题。

- **[Paint-Anything: Unified Any-Color Control for Image Generation and Editing](https://huggingface.co/papers/2609.20816)** — _HF Papers · score 0.68_
  ByteDance Seed 用共享的 hex-prompt 接口统一生成与编辑中的任意颜色控制，配合对象级颜色监督；数据管线通过物体 grounding、感知颜色标注与编辑对合成构建 Paint-500K，并处理真实图像阴影导致的标签近似问题。
- **[StableVQ: Practical Guidelines for Stable Vector-Quantized Tokenizer Training](https://huggingface.co/papers/2609.26774)** — _HF Papers · score 0.62_
  Kuaishou 认为 VQ 训练不稳定的根因是 Encoder-Decoder 与 Codebook 训练纠缠——两者都无法独立履责，只能靠偶然协作；StableVQ 重新界定各模块的学习目标，让各自独立成立。
- **[RULER: Instance-aware Rubric Rewards for SVG Generation](https://huggingface.co/papers/2609.25270)** — _HF Papers · score 0.60_
  inclusionAI 先实证 VLM judge 的多轴 rubric 在样本间与指令内都比 CLIP/Aesthetic 标量更贴合人类判断，再把每条指令转成实例感知 rubric 作为 RL 奖励，避免标量指标在风格化矢量内容上的 reward hacking。

### 🎬 Video Generation

**本周一句话**: 视频生成正在从"画得好看"转向"可控、可验证、可解释"：reference 控制被细化为保留/解耦/路由，reward 用 rubric 消除 scalar drift，甚至开始做运动规划的机制可解释性研究。

- **[OmniVBench: A Benchmark and Large-Scale Dataset for Omni Reference-to-Video Generation](https://huggingface.co/papers/2609.22069)** — _HF Papers · score 0.86_
  Tencent 指出既有 R2V 基准参考类型与组合覆盖有限、只评整体一致性而忽略参考因子是否被正确保留/解耦/路由；OmniVBench 扩展参考类型与细粒度控制任务，并配套 Omni-R2V 数据集缓解训练资源稀缺。
- **[VideoGen-Agent: Reinforcing Video Generation Agents](https://huggingface.co/papers/2609.24997)** — _HF Papers · score 0.78_
  Princeton 用多任务 agentic RL 训练多模态 agent，通过多轮交互协调增强、生成、验证三类外部工具，应对需要专门知识、特定身份、物理一致性或有序事件的 prompt；先在教师轨迹上 SFT 建立工具使用行为，再用 RL 精炼。
- **[Why Do Video Diffusion Models Violate Physics? Unveiling the Flaws in Attention Mechanisms](https://huggingface.co/papers/2609.23658)** — _HF Papers · score 0.76_
  首个针对文生视频扩散模型"运动规划"过程的可解释性研究：运动轨迹在早期去噪阶段形成（"先形状后细节"），结合 cross-attention 轨迹模式与因果 head 贡献定位出驱动运动规划的特定 attention head 子集，并发现 RoPE 诱导了过度的（空间）扩散。
- **[The Past Frames the Future: Memory for Autoregressive Video Generation](https://huggingface.co/papers/2609.28466)** — _HF Papers · score 0.75_
  系统综述自回归视频生成的记忆机制：在严格受限的上下文窗口、存储与算力下，实体身份、动态状态与干预引发的因果变化往往在相关性消失前就已被挤出活跃上下文，这是长程时间持久性的根本瓶颈。
- **[RewardVerse: Rubric-Guided Policy Optimization for Video Reward Modeling](https://huggingface.co/papers/2609.22947)** — _HF Papers · score 0.73_
  Tencent 针对视频 reward model 的 scalar drift（评分尺度在不同 prompt 间塌缩或漂移）问题，借鉴专业人工标注工程，在评测查询与打分器之间引入动态 rubric 作为中间表示，替代无约束直接打分。
- **[WanPE: Towards Cinematic Prompt Enhancement for Modern Text-to-Video Generation](https://huggingface.co/papers/2609.30221)** — _HF Papers · score 0.72_
  397B 参数的 prompt 增强模型，在 1.05M 真实视频上训练，通过视频接地的反向构造生成镜头级电影化规划（动作、镜头轨迹、灯光、声音），并用 Semantic-Consistency GRPO 跨镜头与跨时间保持用户需求；配套人工标注的 WanPEval。

### 🤖 VLA & Embodied

**本周一句话**: 具身侧出现两条清晰分歧：一条主张把 3D grounding 显式做进机器人基础模型（而非从演示中隐式学习），另一条则测试 VLM 的"数字智能"能否通过极简离散动作接口直接迁移到物理世界。同时失败恢复与空间音频感知开始被单独建模。

- **[OmniEcho: Spatial Audio Understanding for Embodied Agents](https://huggingface.co/papers/2609.23407)** — _HF Papers · score 0.84_
  PKU 的 OmniEchoBench 覆盖 6 类任务、197 个真实空间视听场景、2,972 个 QA 对与 900 个导航样本，音频为 30 个真实环境采集的一阶 Ambisonics；配套可控空间音频渲染管线提供几何一致的规模化训练监督。
- **[Grounded Action Model: 3D Grounding as a Foundation for Robotics](https://huggingface.co/papers/2609.23863)** — _HF Papers · score 0.80_
  GAM 主张现有 VLA/WAM 骨干并不直接要求度量 grounding，只能从机器人演示中隐式学习；GAM 接受语言、点或框 prompt，先转成共享的 object-centric 表示（目标聚焦视觉特征 + 度量物体几何），再经多流 transformer 与机器人状态历史混合。
- **[CARE: Experience-Guided Atomic Corrective Execution for Vision-Language-Action Policies](https://huggingface.co/papers/2609.24118)** — _HF Papers · score 0.74_
  不靠人工设计或随机扰动生成纠正数据，而是收集失败 rollout、建模分阶段的失败后偏差分布，据此合成代表性失败状态与纠正演示；推理时结合分阶段规划与物理接地的 3D 监控触发原子调整或重操作，同时保留任务进度。
- **[Transferring the Intelligence of VLMs to Robotic Control](https://huggingface.co/papers/2609.22966)** — _HF Papers · score 0.72_
  RoboDawn 用一组紧凑的离散平移/旋转/夹爪命令把机器人控制暴露给 agentic VLM，VLM 闭环观察视觉状态、推理下一步动作、执行并据结果调整后续决策，直接检验数字世界智能能否跨 embodiment 与任务鸿沟迁移。
- **[How to Use NVIDIA Warp and MjWarp to Accelerate Robotics Simulation and Learning Workflows](https://huggingface.co/blog/nvidia/how-to-use-nvidia-warp-and-mjwarp)** — _HF Papers · score 0.65_
  NVIDIA 教程，介绍用 Warp 与 MjWarp 加速机器人仿真与学习工作流，面向 embodied 训练基础设施搭建。

### 🌍 World Models

**本周一句话**: 世界模型开始补"认知基础"这一课：一边用认知科学启发的任务集训练客体永久性，一边用隐式 3D 记忆与几何原生 latent 解决长程跨视角一致性，同时出现了跨 video/spatial/embodied 三轨的统一评测。

- **[HappyWorld-Bench](https://huggingface.co/papers/2609.24308)** — _HF Papers · score 0.88_
  Alibaba 的层级能力框架含六项世界能力（W1–W6），从生成式构建到统一世界建模，实例化在 video / spatial / embodied 三条独立评测轨道上，共 1,138 视频 prompt、300 空间场景、254 embodied 用例；HappyWorld-Arena 组织人类 A/B 对比并导出排名。
- **[Training Object Permanence in World Models](https://huggingface.co/papers/2609.28654)** — _HF Papers · score 0.80_
  CMU 的 WROP 数据基础设施含 150 个手工设计的认知科学启发任务、分属 6 个认知类别；Blender 生成器随机化速度、光照、相机角度等干扰参数而保持任务认知结构，每任务产出 1 万+ 样本，并发布 1.5M 规模数据集与现有视频模型基准。
- **[WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory](https://huggingface.co/papers/2609.24984)** — _HF Papers · score 0.78_
  Tencent ARC 让请求的视角决定多视角证据如何压缩进视频生成器有限的 token 预算：与生成器联合训练的记忆编码器与 pose 条件读出模块，在去噪前把历史观察整合成固定数量的目标视角特定 token，无需显式深度对应；结合近期时间上下文与少步蒸馏支持流式场景探索。
- **[GAE: Learning a Geometry-Native Latent Space for 3D-Consistent World Generation](https://huggingface.co/papers/2609.24981)** — _HF Papers · score 0.72_
  Tencent ARC 认为 3D 不一致不只是建模问题而是表示问题：生成器演化外观中心 latent，感知模型则在语义丰富空间中恢复几何。GAE 把几何基础模型特征重参数化为紧凑 latent，可联合解码为外观、深度、相机与点图，再用标准条件流支持多样生成。
