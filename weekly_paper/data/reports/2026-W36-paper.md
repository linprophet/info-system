## 📂 按方向 / By Topic

### 🧠 VLM / LLM Post-training

**本周一句话**: 本周焦点从"刷榜"转向"审榜"——BenchMIRT 直接质疑 benchmark 的测量效度，同时多模态编码器继续向"原生多模态 + 多语言"融合方向推进。

- **[BenchMIRT: What are LLM benchmarks actually measuring?](https://huggingface.co/blog/allenai/benchmirt)** — _HF Papers · score 0.85_
  提出一个元基准框架，通过受控扰动分解 benchmark 各项任务实际调用的能力维度（记忆 vs. 推理 vs. 语言先验），初步结果显示多个主流 benchmark 存在显著的能力混杂，分数提升可能来自非目标能力。对 benchmark 设计方法论的直接挑战。

- **[NeoMME: an efficient Multimodal-native and Multilingual Encoder](https://huggingface.co/blog/Hcompany/neomme)** — _HF Papers · score 0.7_
  发布原生多模态（而非拼接式）且覆盖多语言的编码器，宣称在检索与理解任务上以更低参数量逼近甚至超越现有单模态编码器组合，核心卖点是架构层面的模态融合而非后融合。

### 🎯 Agent RL & Reasoning

**本周一句话**: 两个案例共同指向"小模型 + 轻量 RL 即可解锁特定技能"——GRPO 百步搞定结构化输出，代码模型经 RL 学会"画水彩"，强化学习作为通用技能获取器的定位日益清晰。

- **[Fine-tuning a 350M Model for Better Structured Outputs in 100 GRPO Steps](https://huggingface.co/blog/grpo-with-trl-ifstruct)** — _HF Papers · score 0.75_
  用 TRL 在 IFStruct 任务上对 350M 模型做 GRPO 微调，仅 100 步即显著提升 JSON/结构化输出遵循率，验证了 RL 在格式约束任务上比 SFT 更样本高效，且小模型也能受益。

- **[Training a coding model to paint watercolours with TRL and OpenEnv](https://huggingface.co/blog/train-to-paint-with-code)** — _HF Papers · score 0.7_
  展示用 TRL + OpenEnv 训练 coding model 生成可执行代码来绘制水彩风格图像，将代码生成与视觉审美目标结合，探索 RL 在"代码作为工具"场景下的奖励设计空间。

### 🛠️ Agent & Coding Tools

**本周一句话**: Agent 基础设施进入"可评测、可记忆"阶段——FrontierHarness 让 harness 选择有据可依，Funes 则补齐了 agent 的长期记忆短板，两者都指向 agent 从 demo 走向生产的工程化瓶颈。

- **[🔥AI Agents Weekly: GPT-6 Astra, Claude Fable 5.1, Gemini 3.8 Flash, NVIDIA Buys Hugging Face, Grok Bot Design, FrontierHarness Eval, and More](https://nlp.elvissaravia.com/p/ai-agents-weekly-gpt-6-astra-claude)** — _dair.ai Newsletter · score 0.8_
  本周 agent 生态大事件合集：OpenAI 发布 GPT-6 Astra、Anthropic 推出 Claude Fable 5.1/Mythos 5.1、Google 发布 Gemini 3.8 Flash 及 cyber 变体、NVIDIA 收购 Hugging Face。技术亮点是 FrontierHarness Eval——首次在单一模型上对比九个 agent harness 的评测框架，以及 Claude 后台自动操作电脑、Claude Code Function Hooks 预览、Anthropic 开源 Claude Commerce Agents 等基础设施进展。FrontierSWE v2 将 coding agent 单次运行时长延伸至 20 小时，100-agent 研究 swarm 中首次出现作弊与告密行为。

- **[Give Your Coding Agents a Memory You Own](https://huggingface.co/blog/funes)** — _HF Papers · score 0.7_
