### 🎯 Agent RL & Reasoning

**本周一句话**: OPD（on-policy distillation）家族持续扩张——从 token 级反馈（SecOPD）到多教师调度（D³-MOPD、Open-MOPD），再到与 RLVR 融合（OPDVR），密集监督信号成为 post-training 的核心杠杆。

- **[CyberFactory: Scaling Cyber Security Capabilities with Instances from the Wild](https://huggingface.co/papers/2608.23181)** — _HF Papers · score 0.8_
  统一开源框架打通数据构建、轨迹合成、模型训练，覆盖 PoC 生成、漏洞修补、CyberQA 三类任务，解决开源安全模型缺乏可复现训练方案的问题。
- **[OraRL: Annotations as Rollouts for Video MLLMs](https://huggingface.co/papers/2608.20492)** — _HF Papers · score 0.75_
  发现标注的"第二角色"：作为 oracle rollout 进入 on-policy 组成为直接正优化目标，并识别"advantage inversion"失败模式——高奖励 oracle 抬高基线反而反转正优势。
- **[SecOPD: Mitigating Adaptive Prompt Injections by On-Policy Distillation](https://huggingface.co/papers/2608.21500)** — _HF Papers · score 0.75_
  现有防御微调用序列级反馈（DPO/GRPO）无法定位不安全 token，SecOPD 提供 token 级反馈引导防御微调，针对自适应 prompt 注入。
- **[Open-MOPD: Diagnosing and Fixing Capability Imbalance in Multi-Teacher On-Policy Distillation](https://huggingface.co/papers/2608.19098)** — _HF Papers · score 0.75_
  在 SmolLM3-3B 上建立受控 M-OPD 基准（oracle routing），发现标准 M-OPD 仅捕获 35.6% 的可用 headroom，指令跟随等简洁任务能力整合严重不足。
- **[Best Practice Critic Optimization](https://huggingface.co/papers/2608.23566)** — _HF Papers · score 0.75_
  BPCO 组合 DPPO、奖励范围约束的价值预测、MC 价值目标、未归一化策略优势、长度自适应 GAE，实现稳定 critic-based RL；critic 可条件于 reward 定义信息（参考答案/评分标准）。
- **[On-policy Distillation with Verifiable Reward](https://huggingface.co/papers/2608.24696)** — _HF Papers · score 0.75_
  OPDVR 无缝融合 OPD 的密集 token 级监督与 RLVR 的任务级正确性，无需新增超参数——OPD 提供密集信号，RLVR 提供正确性约束。
- **[WarpSAC: Towards the Pinnacle of Scalable Off-policy RL](https://huggingface.co/papers/2608.24479)** — _HF Papers · score 0.7_
  8 个 benchmark 家族受控实验证明：RL stabilizers 是数据 regime 依赖的——参数归一化在窄回放覆盖时有用但限制价值拟合，clipped double-Q 在高吞吐操作中可放宽。
- **[TTPO: Test-Time Policy Optimization](https://huggingface.co/papers/2608.27448)** — _HF Papers · score 0.7_
  发现伪标签失败的不对称性：与伪标签不一致的 rollout 无论投票是否正确通常都是错的，据此设计非对称目标——一致 rollout 用 OPSD 蒸馏，不一致的用 Grouped RL 惩罚。
- **[ParaTempo: Efficient Parallel Reasoning via Temporal Confidence](https://huggingface.co/papers/2608.16425)** — _HF Papers · score 0.7_
  训练-free 异步并行推理框架，用"时间置信度"（答案空间收敛度的分支局部度量）做动态分支级控制，替代延迟的最终答案共识或噪声中间探针。
- **[D³-MOPD: Adaptive Dynamic Domain ScheDuling for Efficient Multi-Teacher Distillation](https://huggingface.co/papers/2608.24987)** — _HF Papers · score 0.7_
  零开销调度器复用训练中已产生的 per-domain reverse-KL 信号，在线调整域混合比例——快收敛域少算，慢收敛域多算。
- **[Agent-G²: Gaussian Guidance for Agentic Reinforcement Learning](https://huggingface.co/papers/2608.23318)** — _HF Papers · score 0.7_
  发现 hint-based RL 中有用 guidance 的深度呈高斯带状分布而非单一最优点，据此按任务从高斯分布采样 guidance 深度。

- **[VGI-Bench: Probing Visual Intelligence in Video Generation Models](https://huggingface.co/papers/2608.19583)** — _HF Papers · score 0.85_

- **[InfinityEdit: Infinite Video Editing with a Lightweight Edit-Ignition Adapter](https://huggingface.co/papers/2608.20910)** — _HF Papers · score 0.8_
  突破 in-place 编辑假设：给定前序片段和编辑请求，生成延续流的下一片段——适用于直播重风格化、持续镜头运动等开放流场景。
- **[JoyAI-Echo-1.5: Long-Horizon Audio-Visual Generation for Persistent Stories and Interactive Worlds](https://huggingface.co/papers/2608.23383)** — _HF Papers · score 0.8_

### 🤖 VLA & Embodied

**本周一句话**: VLA 架构在两条路线分化——GigaBrain-0.7 走"大而全"规模化路线，StreamPI 和 Zero-WAM 走"零参数/零样本"效率路线。

- **[GigaBrain-0.7: Scaling Embodied Foundation Models to Emergent Capabilities](https://huggingface.co/papers/2608.15875)** — _HF Papers · score 0.85_
  三系统架构统一理解/预测/动作，预训练扩展到 37,000+ 小时异构具身数据，单阶段对齐训练——跨机器人形态的泛化能力显著提升。
- **[StreamPI: Streaming Multimodal Temporal Modeling for VLA Models](https://huggingface.co/papers/2608.26067)** — _HF Papers · score 0.8_
  零参数为单帧 VLA（如 pi0.5）增加时间推理：instruction-anchored 时间建模将（视觉观测，语言指令）对作为原子时间单元，对内双向注意力融合，跨对因果注意力保持流式推理。
- **[Zero-WAM: In-Context World-Action Modeling from Human Videos](https://huggingface.co/papers/2608.26103)** — _HF Papers · score 0.8_
  将 ICL 范式带入机器人操作：人类视频作为任务规格（比语言更丰富的视觉线索），因果视频-动作模型零样本执行未见任务。
