### 🛠️ Agent & Coding Tools

**本周一句话**: Harness 层成了主战场——RSI（递归自我改进）从模型权重下移到 harness 组件，同时出现一批"harness 组件级消融"和"agent 一致性/成本"的评测工作。另一个信号是 agent 开始被用来重写自己的运行时（GitHub Copilot → Rust）。

- **[Atria Dawn: The Dawn of Agentic Superintelligence](https://huggingface.co/papers/2609.15818)** — _HF Papers · score 0.9_
  InternLM 的 agentic 基础模型，训练管线把工具中介的交互连到可执行环境和外部验证结果（Verifiable Experience Pipeline）。16 个覆盖科研、工程、数字工作的 benchmark 中 5 项最高分，并讨论了 agent 参与自身后继模型研发的 R&D 流程。
- **[ProgramDistill](https://huggingface.co/papers/2609.18805)** — _HF Papers · score 0.87_
  把"从可运行参考应用反推功能"变成可验证 SWE 任务：mine-craft-patch 无人工干预挖出 26 个应用的 1,975 个可重放行为、4,063 个任务。九个前沿 coding agent 中最好的 GPT-6 Astra / Claude Opus 5 只有 49.2%。
- **[Benchmark Radar](https://huggingface.co/papers/2609.11115)** — _HF Papers · score 0.85_
  CMU 的"活"benchmark 数据库与搜索引擎，每日从 37 个来源抓取 benchmark 论文/仓库/数据集，并追踪模型卡与技术报告中的引用和分数历史，解决"这个分数是在什么设置下报的"问题。
- **[An Empirical Study of Harness Design for Coding Agents](https://huggingface.co/papers/2609.20804)** — _HF Papers · score 0.85_
  固定执行循环、只变 planning / action space / context management 三个组件，在 4 个模型 × SWE-Bench Verified + Terminal-Bench 2.1 上跑 176 组匹配设置。核心发现：context 预算越大，context management 的收益越显著。
- **[SoL-Pi](https://huggingface.co/papers/2609.20519)** — _HF Papers · score 0.82_
  NVIDIA 在 harness 层做 RSI：跨大量多样环境扩展 auto-research loop，最终筛出四个可迁移机制（动作执行、上下文压缩、观测处理、委派阅读），在 51 任务 EdgeBench 上验证。
- **[ModularRSI](https://huggingface.co/papers/2609.14857)** — _HF Papers · score 0.8_
  针对 harness RSI 的三个失效点（benchmark 特化、单轨迹更新混淆系统性缺陷与实例细节、单体 harness 难以归因）提出模块化方案，让改进可迁移到未见任务。
- **[Your Agent Aced the Task. Will It Do It Again?](https://huggingface.co/blog/ibm-research/altk-evolve-consistency)** — _HuggingFace TRL Blog · score 0.8_
  IBM Research 的 ALTK-Evolve：指出 agent 一次通过 ≠ 稳定通过，给出 run-to-run 一致性评测，是本周最被低估的一篇（harness 可靠性而非峰值能力）。
- **[Migrating the GitHub Copilot runtime to Rust, using Copilot](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/)** — _GitHub Copilot Blog · score 0.78_
  把 Copilot agent runtime 从 TypeScript/Node 全量重写为 80 万+ 行生产 Rust，128 个 PR 增量落地，大部分代码由 Copilot agent 自己写。是"agent 写 agent 基础设施"最具体的工程案例。

### 🎯 Agent RL & Reasoning

**本周一句话**: 本周最有价值的是两个**负面/诊断性**结果：RLVR 的数据策略选择基本打不过均匀采样，PPO critic 存在系统性 Value Flattening。RSI 的形式化也开始出现（GAI）。

- **[DataFlex-RL](https://huggingface.co/papers/2609.06107)** — _HF Papers · score 0.85_
  统一 GRPO recipe 下比较 13 种 RLVR 数据策略、12 个匹配 seed、Qwen2.5-7B-Base、12 个数学/逻辑/科学 benchmark。均匀 GRPO 比未训练 checkpoint 高 7.76 个点，但八种 rollout 选择/重加权方法相对均匀采样的配对 95% CI 都跨零，三种自适应混合也不敌固定等权混合。
- **[Dream-RSI](https://huggingface.co/papers/2609.14858)** — _HF Papers · score 0.82_
  Google 把探索策略显式化、可编程化（轻量 orchestration 层，不改底层 coding agent），用累积经验驱动探索策略的递归自我改进，绕开在线策略优化在延迟反馈下的 meta-search 难题。
- **[RetireOPD](https://huggingface.co/papers/2609.20784)** — _HF Papers · score 0.75_
  指出 agentic RL 中 self-OPD 的两个问题：有特权信息不等于 teacher 可靠、teacher 监督的收益是阶段依赖的。方案是先训 skill-conditioned teacher，再让 skill-free student 联合 RL + OPD，并用 Adaptive Retire 替代固定蒸馏日程。
- **[Rethinking Critic Learning in PPO](https://huggingface.co/papers/2609.18708)** — _HF Papers · score 0.72_
  发现 PPO critic 的系统性失效模式 "Value Flattening"：用多条 Monte Carlo 续写估出的状态值在中间状态剧烈变化，critic 预测却相对平坦；在 FrozenLake 中随状态空间增大而加剧，归因于 critic loss 的隐式方差惩罚与时间相关状态的冗余更新。
- **[When2Think](https://huggingface.co/papers/2609.19671)** — _HF Papers · score 0.68_
  微软把高效推理形式化为实例级算力分配问题：IDAC 用预计算的准确率/token 用量参考统计做 reward shaping，避免统一长度惩罚在难题上掉点。
- **[XConf](https://huggingface.co/papers/2609.17708)** — _HF Papers · score 0.62_
  反驳"只看当前推理过程"的置信度估计前提，改为把模型自己过往的 graded episode（任务、反思、自报置信、结果、教训）作为经验一起估计置信度。
- **[Generalized Agent Iteration](https://huggingface.co/papers/2609.13406)** — _HF Papers · score 0.5_
  理论/position 论文：把迭代策略改进与递归自我改进统一为同一学习范式的两个 case，试图给 RSI 一个类似 GPI 的形式化框架。

### 🎬 Video Generation

**本周一句话**: 实时/流式成为主线（Vidu S2、Video DeltaNet），同时出现"用程序化重建来考视频理解"的新评测范式（BVB），以及低比特 attention 的部署侧优化。

- **[Vidu S2](https://huggingface.co/papers/2609.11638)** — _HF Papers · score 0.88_
  两个模型：S2-Avatar 支持实时 720p 数字人、可随时更新的动态参考、更强指令跟随（如跳舞）；S2-Editing 支持实时视频流编辑（风格渲染、换衣、换角色、换背景）。并探索了两者的实时空间视频生成可行性，有在线 demo。
- **[BVB (Blender-VideoBench)](https://huggingface.co/papers/2609.15478)** — _HF Papers · score 0.82_
  换掉 QA 式评测：让 agent 把真实视频用代码重建为 Blender 动画场景，统一 sandbox + 共享成本上限，用 Dual VQA（保留多少时空事实）和 Latent Similarity 两个轴打分。
- **[LynnReal-Omni](https://huggingface.co/papers/2609.15863)** — _HF Papers · score 0.72_
  32B 共享多模态 diffusion transformer，统一文生视频、图像条件、参考引导、结构控制、编辑、退化视频修复与长视频生成；动机是"agentic 视觉控制提供稳定性但不保证保真度"，两者结合。
- **[Video DeltaNet](https://huggingface.co/papers/2609.20744)** — _HF Papers · score 0.68_
  局部 softmax attention + 双向线性记忆的混合注意力，线性分支的 Video Delta Attention 每帧更新一次记忆并联合纳入该帧空间 token；配分阶段 teacher-alignment 逐步引入，面向直播视频生成。
- **[VC-Attention](https://huggingface.co/papers/2609.15810)** — _HF Papers · score 0.6_
  训练无关的低比特 attention：指出 value 的 outlier 没有固定通道/时空结构、是输出误差主因（此前工作只平滑 Q/K），并解决低比特 Tensor Core 之间高精度 exp 成为最长流水级的问题。

### 🤖 VLA & Embodied

**本周一句话**: 三个新 benchmark（ReactHuman、VA-Bench）把评测从"被动理解物理"推向"主动获取证据并即时行动"；方法侧则集中攻击 vision-action shortcut 与 action tokenization 的保真度度量。

- **[PhysBrain 1.5](https://huggingface.co/papers/2609.14973)** — _HF Papers · score 0.85_
  从通用 VLM 出发，把语言回答、末端执行器运动、稠密视觉目标都编码为离散序列联合自回归优化；具身监督全部来自人类交互视频，再经人类演示 + 机器人轨迹混合 SFT。
- **[ReactHuman](https://huggingface.co/papers/2609.10895)** — _HF Papers · score 0.85_
  首个物理接地的"类人反应式决策"benchmark：MLLM 作为仿真人形机器人的大脑面对突发家庭危险（接住滑落的盘子、躲开掉落的刀），覆盖 17 类事件、1000+ 逐比特场景。
- **[VA-Bench](https://huggingface.co/papers/2609.19554)** — _HF Papers · score 0.85_
  评测完整 observe-reason-act-revise 闭环：模型只从 RGB 演示学流程、主动选相机视角、发出 metric 笛卡尔指令并根据执行反馈修正；无特权物体位姿、无 oracle 轨迹、无学习动作头，14 个基础任务族 + 7 个留出几何/布局变体 + 五物体长程组合。
- **[Latent Interface Training (LIT)](https://huggingface.co/papers/2609.12641)** — _HF Papers · score 0.78_
  两阶段框架无关策略：先在没有图像的情况下建立空间目标条件的动作先验，再通过 pose-s 约束视觉条件，切断 vision-action shortcut，提升视觉分布偏移下的泛化。
- **[ActionPiece](https://huggingface.co/papers/2609.18487)** — _HF Papers · score 0.72_
  提出 physical rank consistency (PRC) 度量 action tokenization 在重建后是否保留了局部物理距离排序，指出 MSE 这类逐点指标会掩盖"不同上下文所需的动作调整被削弱、扭曲甚至反转"。

### 🧠 VLM / LLM Post-training

**本周一句话**: 效率是绝对主题——KV cache 压缩（DeepSeek-V4.1-Flash、GVA）、注意力稀疏化（SAS）、长度控制（When2Think、EOS mismatch）三条线同时推进；同时出现一个完全开放的 7B 高效训练配方（ZGCM-1）。

- **[DeepSeek-V4.1-Flash](https://huggingface.co/papers/2609.19969)** — _HF Papers · score 0.95_
  552B MoE 多模态模型，支持百万 token 上下文。Causal Encoder-Decoder 架构让 decode 每 token 激活 16B、prefill 仅 8B；针对长程 agent 的 input-heavy 负载，把 prefill 算力、KV cache 的 HBM/SSD 占用与传输带宽作为主要降本目标。
- **[StepAudio 3 Realtime](https://huggingface.co/papers/2609.14005)** — _HF Papers · score 0.85_
  围绕 listen-converse-think-act 循环的音频语言基础模型：Deep Perception 抓声学线索、Seamless Duplex 处理停顿/附和/打断，Think-While-Speaking 让私有推理与语音输出并行。推理模式下 StepAudioChat 宏平均 73.0。
- **[Gemini 3.8 Live / 3.8 Live Extended Thinking](https://deepmind.google/blog/introducing-gemini-3-8-live-and-3-8-live-extended-thinking/)** — _Google DeepMind Blog · score 0.85_
  DeepMind 前沿多模态模型更新，新增 Live 与 Live Extended Thinking 两个版本。
- **[ZGCM-1](https://huggingface.co/papers/2609.13356)** — _HF Papers · score 0.78_
  从零训练的完全开放 7B dense 模型，核心论点是紧凑模型靠"内部思考 + 主动外部工具使用"突破参数容量上限。配方包括交错 gated 滑窗/全注意力、稳定的 FP8 Muon 优化器、16K→64K→256K 渐进课程，以及把交互轨迹重构为 MDP 的 mid-training。
- **[Verifiable Social Reasoning for LLM Assistants (Fuse)](https://huggingface.co/papers/2609.17496)** — _HF Papers · score 0.72_
  Google 的多 agent 仿真框架：带隐藏动机的目标 agent 与其他 agent（含代表用户者）交互，用户再咨询被评测助手来推断动机——ground truth 由构造保证。用 24k 人工标注验证仿真保真度。
- **[When EOS Tokens Disagree](https://huggingface.co/papers/2609.20511)** — _HF Papers · score 0.7_
  微软定位 on-policy distillation 长度膨胀的一个来源：base student 与 post-trained teacher 把停止概率放在不同 EOS token 上（即使声明的停止集合相同），压制了 student 偏好的终止动作。仅对齐解码停止集不够，需把功能等价的 EOS 视为共享语义停止动作。
- **[Grouped Value Attention (GVA)](https://huggingface.co/papers/2609.13285)** — _HF Papers · score 0.68_
  只存分组 value、用学习到的线性映射重建 content key，推理时该映射可吸收进 query，从而在目标 decode 路径上不必物化 content key；另用小型共享解耦 RoPE 通道保留位置信息。在研究的配置下持久 cache 标量比匹配 GQA 少约 45–47%。

### 🌍 World Models

**本周一句话**: 三条不同路线——评测（MiniMax-H3 能否推理物理世界）、跨域统一预测（JEPA-Anything）、可玩性（Zing-0.5 实时联合控制）。

- **[Can MiniMax-H3 Reason About the Physical World?](https://huggingface.co/papers/2609.18323)** — _HF Papers · score 0.82_
  针对 omni-modal 生成模型（MiniMax-H3 在共享 latent 框架里联合音视频生成）提出四维物理世界推理评测框架，追问多模态对齐是否真的提升了世界推理，以及 omni-modal 输入带来了哪些新评测范式。
- **[JEPA-Anything](https://huggingface.co/papers/2609.20800)** — _HF Papers · score 0.78_
  基于 orthogonal predictive factorization 的领域无关世界建模框架：把 latent target 分解为互补因子、用专门通路学习、再在共享预测设计中重组。跨视觉、生物、临床轨迹、控制、分子动力学、物理场、天气七个域评测表征学习、干预预测与 OOD 生成。
- **[Zing-0.5](https://huggingface.co/papers/2609.17909)** — _HF Papers · score 0.78_
  5B 自回归可玩世界模型：统一 magnitude-aware 键盘输入与时间对齐文本指令的联合条件；用 segment-level teacher 通过分布匹配蒸馏监督 block-level 因果 student 做事件尺度增量生成；四步生成实现低成本实时交互。

## 📊 本周观察 / Editor's Note

两个跨方向信号值得注意。其一，**"harness 层"正在取代模型权重成为 RSI 的主战场**：SoL-Pi、ModularRSI、Dream-RSI、RSIAgent、Agora 五篇独立工作都在做 harness/探索策略的自我改进，而 GitHub 用 Copilot 把自家 runtime 重写成 80 万行 Rust 是这条线最硬的工程证据。其二，**效率优化从"训练"全面转向"推理成本结构"**：DeepSeek-V4.1-Flash 的 CED（prefill 8B / decode 16B）、GVA 的 key 重建、SAS 的端到端稀疏化、VC-Attention 的 value outlier，四篇都在攻击同一件事——长上下文/长视频下 KV 与 attention 的部署成本。
